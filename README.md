<h1>Snake Game</h1>
<h2>Gameplay</h2>

<p>Esse jogo foi criado para ser um jogo simples e divertido, onde o jogador pode controlar um serpente que se move pelo tabuleiro, coletando alimentos para aumentar seu tamanho e evitando colidir com as paredes ou com si mesmo.</p>

<h2>Controles</h2>

<p>As teclas de controle são as setas do teclado para mover o serpente.</p>

<h2>Objetivo</h2>

<p>O objetivo do jogo é coletar alimentos para aumentar o tamanho do serpente e evitar colidir com as paredes ou com si mesmo.</p>

<h2>Regras</h2>


<p>O jogo termina quando o serpente colide com as paredes ou com si mesmo.</p>
